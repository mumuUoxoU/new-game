# new-game 🎮

むぅが作ったゲームを置くリポジトリだよ。

## むぅの保管庫

入口は `index.html`（むぅの保管庫）だよ。ゲームの一覧と簡単な説明があって、選んでそのまま遊べるよ。ばくれつスライムのベストスコアも表示されるよ（スコアはブラウザに保存されるよ）。

## むぅのほしあつめ

`hoshiatsume.html` をブラウザで開くだけで遊べる、最初のミニゲームだよ。

### 遊び方

- むぅ（🐱）を左右に動かして、落ちてくる ⭐ をあつめよう
- ⭐ = 10点、💗 = 30点（ボーナス）
- 💣 に当たるとライフが1つ減って、3つ無くなるとゲームオーバー
- 時間が経つほど速くなるよ。ベストスコアはブラウザに保存されるよ

### 操作

- スマホ：ドラッグ
- PC：マウス、または ← → キー

## むぅのばくれつスライム

`bakuretsu-muu.html` をブラウザで開いて遊べるよ。マリオRPGの「爆裂カブトムシ」をむぅ風にアレンジしたスコアアタックだよ。

### 遊び方

- むぅ（🐱）を左右に動かして、落ちてくるスライムに ⭐ をぶつけよう
- スライムがはじけると星が飛び散って、別のスライムに当たると連鎖で点数が倍々に増えるよ（1つ最大9999点）
- スライムや飛び散った星に当たるとダウン。3秒以内の連打で復活できて、ダウンするたびに必要な連打数が増えるよ
- 💗 を取ると復活に必要な連打数が減って楽になるよ

### 操作

- スマホ：ドラッグで移動、タップ長押しで星を発射
- PC：← → キーで移動、スペースで発射

## むぅのばくれつスライム【ハードモード】

`bakuretsu-hard.html` だよ。ノーマルモードでベストスコアが10,000点を越えると、保管庫の「あそぶ」の下にハードモードのボタンが解禁されて、タッチで遊べるようになるよ（解禁前はロック表示でタッチできないよ）。

### ノーマルとの違い

- スライムが画面の左・右・下で跳ね返って、ずっと動き回るよ。横移動は速めだよ
- はじける星は5個で、消えずに飛び回るよ
- 敵（スライム）・自機（むぅ）・星の表示がノーマルより少し小さいよ
- 当たり判定は画面の中だけ。スライムは画面の少し上から落ちてきて、入ってきたら表示されるよ

## むぅの大連鎖モード

`bakuretsu-chain.html` だよ。ハードモードでベストスコアが10,000点を越えると、保管庫のハードモードの下に追加されるよ（それまでは表示もヒントも出ないよ）。

### ルール

- 制限時間は1分。💗 を取ると +1秒
- 自機はスライムや星に当たらない（ダウンしない）よ
- 星は画面外に出るまで消えないよ。はじける星は5〜7個
- スライムの出現スピードはハードの5倍、画面内の敵は最大250体まで
- スライムの横移動と落ちる速度はハードの2倍
- 0秒時点で連鎖していれば、連鎖が終わるまで続行。その間は移動とショットはできないよ
- 連鎖の得点は上限なし。ただし上がり方は倍々ではなく +1 ずつだよ
- スライム・自機・星の表示はノーマルの半分のサイズだよ
